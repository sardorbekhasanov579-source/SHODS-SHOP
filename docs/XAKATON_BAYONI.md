# SHODS SHOP — qisqa loyiha bayoni (1 betga mos)

**Muammo:** institut talabalari yaratgan moddiy va raqamli mahsulotlar va o‘zlari bajara oladigan xizmatlar haqidagi e’lonlar tarqoq. Xaridor izlaydi, narxlarni solishtiradi, sotuvchi esa buyurtmani bir markazda ko‘rmaydi.

**Yechim:** SHODS SHOP — OTM talabalari uchun uch tildagi responsive PWA. Har bir hisob bir vaqtda xaridor ham, sotuvchi ham bo‘lishi mumkin. Sotuvchi mahsulot yoki xizmat nomi, narxi, turi, miqdori, rasm, manzil, faol/nofaolligini kiritadi; xaridor qidiradi, savatga qo‘shadi, miqdorni tanlaydi, demo to‘lov bilan buyurtma yuboradi; sotuvchi uni ko‘radi. Boshqa imkoniyatlar: portfolio, yakunlangan xariddan keyingi baholar va sharhlar, yordam markazi, admin moderatsiyasi, demo AI tavsiyalari.

**Vositalar:** React 19, Vite 6, Node.js 20+, HTTP API; JSON ma’lumot ombori (`server/data/db.json`). PWA manifest/service worker. Gemini va Telegram bot ixtiyoriy server integratsiyasi.

**Xarajat (5 sotuvchi, 100 xaridor, 4 hafta):** bir mahalliy sinov kompyuterida dastur litsenziyasi va demo to‘lov uchun **0 so‘m**. Elektr/Internet/hostingning aniq narxi sharoit va provayderga bog‘liq, shuning uchun umumiy sarfni 0 so‘m deb da’vo qilib bo‘lmaydi. Tashqi Gemini API va ommaviy HTTPS hosting ishlatilsa, ulardan foydalangan miqdor bo‘yicha alohida xarajat kelib chiqadi.

**Cheklovlar:** haqiqiy pul yechilmaydi, fayllarni raqamli yetkazib berish va logistika avtomatlashtirilmagan. DB JSON demo bo‘lib, katta trafik uchun PostgreSQL zarur. Kalitsiz tasvir o‘xshashligi vizual xesh, semantik AI emas. Telegram bot ulanmagan bo‘lsa demo ro‘yxatdan o‘tish; SMS yo‘q.
